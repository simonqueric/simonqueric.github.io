Your publishing workflow

  1. Edit entries and click Save entry to draft.
  2. Click Export content.js. Your browser downloads the file.
  3. Replace the existing public/content.js with that file (keep the exact name).
  4. For GitLab Pages, commit the change to your default branch. The included pipeline publishes it.

This editor runs in your browser. It does not log in to GitLab or modify your live site directly. Opening it online is fine; only someone with repository write access can publish changes.
